# Jeweller OS frontend

React UI for jewellery shops and Ahmed Solutions administration.

```bash
npm ci
npm run dev
```

Open http://localhost:5173. Start the backend separately with `npm run dev` inside `../backend`. Vite proxies `/api` to http://127.0.0.1:4000. There are no database credentials in the frontend.

`npm run build` creates `dist/`. For production, keep the built folder beside `../backend`; Express serves it from the same origin. See `../README.md` for account setup and the combined demo.
